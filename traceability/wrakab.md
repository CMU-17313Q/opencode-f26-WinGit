# Traceability: Wassim Rakab (wrakab)

**Target feature:** The `/context` command in the opencode TUI, which lists the files the agent has loaded into the current session with each file's path and approximate token count. The list and token counts are built by `contextFiles` in `packages/opencode/src/session/message-v2.ts`, which `Session.contextFiles` in `packages/opencode/src/session/session.ts` calls after applying /undo and compaction. The dialog is `packages/tui/src/component/dialog-context.tsx` (with `packages/tui/src/util/context-files.ts`), registered in `packages/tui/src/app.tsx`.

## Requirement changes

| ID | Original requirement (P4A) | Revised requirement | Why it changed |
|---|---|---|---|
| R6 | A file's token count is based on the length of the text the agent read, so twice the text gives about twice the tokens. (Acceptance: a 400-character file shows ~100 tokens, an 800-character file ~200.) | A file's token count is the length of the text the agent read for it, divided by 4 and rounded up, so doubling that text doubles the count, give or take one token of rounding. | Checkability: "about twice" and "~100" can't be checked by a test, since there is no line between passing and failing. The new wording keeps what Adam and Sultan asked for (the count grows with the file) and states the exact rule, including the one-token rounding difference when the length isn't a multiple of 4. |
| R8 | /context matches the file reads shown in the chat's tool messages: one entry per file those messages show, and no others. | /context lists exactly the files whose read, edit or write text is still in the model's context: one entry per file, in the order first read, each with its text length divided by 4, rounded up. Reads removed by /compact, and tools that don't open files, add nothing. | Conflict: after /compact, the old read still shows in the chat, but its text is no longer in the model's context. Listing it would match the chat but overstate what the agent actually has, which goes against what Sultan asked for in C-15 (list only files whose content is still kept). The check against the tool messages stays, limited to the ones still in context. |
